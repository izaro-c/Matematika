# `content-pages/`

Templates that render authored MDX from `content/mdx/`.

| Folder | When to use |
|---|---|
| `screens/` | Route screens (`TheoremPage`, `ExercisePage`, …) |
| `shared/` | Default shell pieces shared across MDX types |
| `exercise/` | Exercise UI + interactives (Hueco, …) |
| `study-plan/` | Study plan / progress UI |

Add a new sibling folder only if that MDX type needs a clearly different React UI.
