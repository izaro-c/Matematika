<Capitular letra="E" />l quinto <ConceptLink targetId="axioma-incidencia-5">axioma de incidencia</ConceptLink> garantiza la extensión no degenerada de toda superficie <ConceptLink targetId="plano">plana</ConceptLink>. Exige que todo plano albergue una base mínima de tres <ConceptLink targetId="punto">puntos</ConceptLink> no <ConceptLink targetId="colinealidad">alineados</ConceptLink>.

<Definicion title="">
  Para todo <ConceptLink targetId="plano">plano</ConceptLink> $\alpha \in \mathcal{E}$, existen al menos tres <ConceptLink targetId="punto">puntos</ConceptLink> distintos $A, B, C \in \mathcal{P}$ no <ConceptLink targetId="colinealidad">colineales</ConceptLink> tales que $A, B, C$ inciden en $\alpha$:
  $$
  \forall \alpha \in \mathcal{E} \implies \exists A, B, C \in \mathcal{P} \ (A \neq B \land B \neq C \land A \neq C \land A, B, C \in \alpha \land \text{no colineales})
  $$
</Definicion>

### Dualidad axiomática

Mientras que el <ConceptLink targetId="axioma-incidencia-4" isDependency={false}>axioma I.4</ConceptLink> demuestra la existencia del <ConceptLink targetId="plano">plano</ConceptLink> a partir de tres <ConceptLink targetId="punto">puntos</ConceptLink> no <ConceptLink targetId="colinealidad">colineales</ConceptLink>, el axioma I.5 establece la relación recíproca: todo plano dado contiene necesariamente una base no colineal de puntos.
