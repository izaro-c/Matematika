    buckets={[

      { id: "obtusangulo", title: "Triángulo obtusángulo (un ángulo > 90°)" }
    ]}
    items={[
      { id: "t1", content: "$90^\\circ, 45^\\circ, 45^\\circ$", bucketId: "rectangulo" },
      { id: "t2", content: "$60^\\circ, 60^\\circ, 60^\\circ$", bucketId: "acutangulo" },
      { id: "t3", content: "$120^\\circ, 30^\\circ, 30^\\circ$", bucketId: "obtusangulo" },
      { id: "t4", content: "$3, 4, 5\\text{ (lados)}$", bucketId: "rectangulo" }
    ]}
  >
    <Clasificador.ErrorComun titulo="No reconocer la terna 3, 4, 5 o el ángulo obtuso">
      El triángulo de <ConceptLink targetId="lado">lados</ConceptLink> 3, 4 y 5 no da sus ángulos, pero sus <ConceptLink targetId="longitud">longitudes</ConceptLink> satisfacen $3^2 + 4^2 = 5^2$; por el <ConceptLink targetId="teorema-pitagoras-reciproco" isDependency={true}>recíproco del teorema de Pitágoras</ConceptLink>, el ángulo opuesto al lado de longitud 5 es recto. Por otra parte, basta un solo ángulo obtuso para que el triángulo sea obtusángulo.
    </Clasificador.ErrorComun>

    <Clasificador.Resolucion>

      - **Acutángulos**: sus tres ángulos miden menos de $90^\circ$ ($60^\circ, 60^\circ, 60^\circ$).
      - **Obtusángulos**: tienen un ángulo de más de $90^\circ$ ($120^\circ, 30^\circ, 30^\circ$).
    </Clasificador.Resolucion>
  </Clasificador>
