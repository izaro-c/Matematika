<Capitular letra="D" />ado un <ConceptLink targetId="triangulo-rectangulo">triángulo rectángulo</ConceptLink> <VisualBind element="polyABC" color="carbon">$\triangle ABC$</VisualBind> con <ConceptLink targetId="perpendicular">ángulo recto</ConceptLink> en el <VisualBind element="pC" color="carbon">vértice $C$</VisualBind>, se conoce que la hipotenusa mide $c = |\overline{AB}| = 10$ unidades (<VisualBind element="segAB" color="mora">hipotenusa $c$</VisualBind>) y el cateto horizontal mide $b = |\overline{BC}| = 8$ unidades (<VisualBind element="segBC" color="terracota">cateto $b$</VisualBind>). Se requiere calcular la longitud exacta del <VisualBind element="segCA" color="canela">cateto vertical $a = |\overline{CA}|$</VisualBind>.

  Identifica la formulación algebraica adecuada para plantear el <ConceptLink targetId="teorema-pitagoras">teorema de Pitágoras</ConceptLink> en base a los datos conocidos:

  <Pregunta

    correct="opt_correcta"
    texto="¿Cuál de las siguientes relaciones describe correctamente el teorema para este triángulo?"
    opciones={[
      { value: 'opt_correcta', texto: "$a^2 + 8^2 = 10^2$" },
      { value: 'opt_suma_catetos', texto: "$a^2 = 10^2 + 8^2$", feedback: "Has planteado la fórmula sumando las áreas como si buscaras la hipotenusa. Recuerda que la hipotenusa ya es conocida ($c=10$). Para despejar un cateto, debes restar las áreas: $a^2 = c^2 - b^2$." },
      { value: 'opt_hipotenusa_err', texto: "$10^2 + a^2 = 8^2$", feedback: "Has sumado el cuadrado de la hipotenusa con el cateto. Recuerda que la hipotenusa al cuadrado debe quedar sola en el miembro de la igualdad: $a^2 + b^2 = c^2$." }
    ]}
  >
    <Pregunta.ErrorComun titulo="Sumar los cuadrados de los lados conocidos en lugar de restarlos">
      Un error habitual al despejar un cateto es sumar las superficies conocidas: $a^2 = c^2 + b^2 = 100 + 64 = 164 \implies a \approx 12.8$. En todo triángulo rectángulo, la hipotenusa es estrictamente el lado de mayor longitud ($c > a$ y $c > b$); un cateto nunca puede superar a la hipotenusa.
    </Pregunta.ErrorComun>

    <Pregunta.Resolucion>
      Por el teorema de Pitágoras $a^2 + b^2 = c^2$. Sustituyendo los datos conocidos $b = 8$ y $c = 10$, obtenemos la relación:
      
      <Formula>
        $$ a^2 + 8^2 = 10^2 $$
      </Formula>
    </Pregunta.Resolucion>
  </Pregunta>

    <Emparejar.Resolucion>

      <Formula>

      </Formula>
    </Emparejar.Resolucion>

<ExerciseStep

  numero={3}
  titulo="Secuencia de deducción algebraica"
  questionIds={["p3_q1"]}
  dependeDeQuestions={["p2_q1"]}
>
  Ordena de forma lógica los pasos algebraicos para despejar la longitud exacta del cateto $a$:

  <Ordenacion
    id="p3_q1"
    pregunta="Arrastra los pasos para colocarlos en el orden deductivo correcto:"
    pasos={[
      "$a^2 + 8^2 = 10^2$",
      "$a^2 + 64 = 100$",
      "$a^2 = 100 - 64$",
      "$a = \\sqrt{36} = 6$"
    ]}
  >
    <Ordenacion.ErrorComun titulo="Extraer la raíz cuadrada antes de simplificar la resta">
      No se puede aplicar la raíz término a término ($\sqrt{100 - 64} \neq \sqrt{100} - \sqrt{64} = 10 - 8 = 2$). Primero se debe calcular la diferencia $100 - 64 = 36$ y después extraer la raíz.
    </Ordenacion.ErrorComun>

    <Ordenacion.Resolucion>
      El orden deductivo correcto es:
      - Planteamiento: $a^2 + 8^2 = 10^2$
      - Cálculo de potencias: $a^2 + 64 = 100$
      - Despeje de la incógnita cuadrática: $a^2 = 100 - 64 = 36$
      - Extracción de raíz cuadrada: $a = \sqrt{36} = 6$
    </Ordenacion.Resolucion>
  </Ordenacion>
</ExerciseStep>
