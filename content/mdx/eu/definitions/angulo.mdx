### Sailkapena neurtze-amplitudearen arabera

Angeluak beren $\alpha$ neurri-amplitudeari dagokion zenbakizko tartearen arabera sailkatzen dira:

| Angelu mota | Neurri-tartea radianetan | Neurri-tartea graduetan |
|---|---|---|
| <ConceptLink targetId="angulo-agudo">Zorrotza</ConceptLink> | $0 < \alpha < \frac{\pi}{2}$ | $0^\circ < \alpha < 90^\circ$ |
| <ConceptLink targetId="angulo-recto">Zuzena</ConceptLink> | $\alpha = \frac{\pi}{2}$ | $\alpha = 90^\circ$ |
| <ConceptLink targetId="angulo-obtuso">Kamutsa</ConceptLink> | $\frac{\pi}{2} < \alpha < \pi$ | $90^\circ < \alpha < 180^\circ$ |
| <ConceptLink targetId="angulo-llano">Laua</ConceptLink> | $\alpha = \pi$ | $\alpha = 180^\circ$ |
| Konkaboa | $\pi < \alpha < 2\pi$ | $180^\circ < \alpha < 360^\circ$ |

### Propietateak

- **<ConceptLink targetId="bisectriz">Erdibitzailearen existentzia</ConceptLink>**: Angelu ez-nulu bakoitzak <ConceptLink targetId="bisectriz">erdibitzaile</ConceptLink> bakarra du, bi angelu kongruentetan banatzen duena.
- **<ConceptLink targetId="angulos-suplementarios">Aditivitate angeluarra</ConceptLink>**: $\overrightarrow{OC}$ zuzenerdi bat $\angle AOB$-ren barnean badago, orduan $\text{m}(\angle AOC) + \text{m}(\angle COB) = \text{m}(\angle AOB)$ betetzen da ezinbestean.
- **<ConceptLink targetId="congruencia">Kongruentzia-irizpidea</ConceptLink>**: Bi angelu kongruenteak dira ($\angle AOB \cong \angle CDE$) beren neurri angeluarrak berdinak badira soilik.
