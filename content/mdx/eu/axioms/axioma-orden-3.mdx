<Definicion title="II.3 axioma (Bitartekotasun linealaren esklusibotasuna)">
$\mathcal{P}$-ko <VisualBind element="lineDE" color="carbon">$\ell$</VisualBind> <ConceptLink targetId="recta">zuzen</ConceptLink> berean <ConceptLink targetId="incidencia">intziditzen</ConceptLink> duten <VisualBind element="pA" color="terracota">$A$</VisualBind>, <VisualBind element="pB" color="terracota">$B$</VisualBind> eta <VisualBind element="pC" color="terracota">$C$</VisualBind> <ConceptLink targetId="punto">puntu</ConceptLink> desberdinen edozein <ConceptLink targetId="terna">hirukoterako</ConceptLink>, $A * B * C$, $B * A * C$ edo $A * C * B$ bitartekotasun-erlaziotatik gehienez bat da egiazkoa:

$$
\forall A, B, C \in \mathcal{P} \ \Biggl( \Bigl(A \neq B \land B \neq C \land A \neq C \land \exists \ell \in \mathcal{L} \, (A \, \mathbf{I} \, \ell \land B \, \mathbf{I} \, \ell \land C \, \mathbf{I} \, \ell)\Bigr) \implies \neg\Bigl( (A * B * C \land B * A * C) \lor (A * B * C \land A * C * B) \lor (B * A * C \land A * C * B) \Bigr) \Biggr)
$$
</Definicion>
