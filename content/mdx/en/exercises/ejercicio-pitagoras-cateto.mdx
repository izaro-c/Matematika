  Identify the equality that expresses the <ConceptLink targetId="teorema-pitagoras" isDependency={true}>Pythagorean theorem</ConceptLink> with the known data:

  <Pregunta
    id="p1_q1"
    correct="opt_correcta"
    texto="Which of the following relations correctly expresses the theorem for this triangle?"
    opciones={[

      { value: 'opt_suma_catetos', texto: "$b^2 = 10^2 + 8^2$", feedback: "You added the areas as if you were looking for the hypotenuse, but the hypotenuse is already known ($c = 10$). To solve for a leg you must subtract: $b^2 = c^2 - a^2$." },
      { value: 'opt_hipotenusa_err', texto: "$10^2 + b^2 = 8^2$", feedback: "You added the square of the hypotenuse to the square of a leg. In the theorem, the square of the hypotenuse stands alone on one side of the equality: $a^2 + b^2 = c^2$." }
    ]}
  >
    <Pregunta.ErrorComun titulo="Adding the squares of the known sides instead of subtracting them">
      A common error when solving for a leg is to add the known areas: $b^2 = c^2 + a^2 = 100 + 64 = 164 \implies b \approx 12.8$. In every <ConceptLink targetId="triangulo-rectangulo">right triangle</ConceptLink> the <ConceptLink targetId="hipotenusa">hypotenuse</ConceptLink> is the longest <ConceptLink targetId="lado">side</ConceptLink> ($c > a$ and $c > b$), so a leg can never exceed it.
    </Pregunta.ErrorComun>

    <Pregunta.Resolucion>
      By the Pythagorean theorem, $a^2 + b^2 = c^2$. Substituting the data $a = 8$ and $c = 10$ gives:
      
      <Formula>
        $$ 8^2 + b^2 = 10^2 $$
      </Formula>
    </Pregunta.Resolucion>
  </Pregunta>

      <Formula>

<ExerciseStep

  numero={3}

  questionIds={["p3_q1"]}

>
  Order the algebraic steps that solve for the length of the leg $b$:

  <Ordenacion
    id="p3_q1"
    pregunta="Drag the steps into the correct order:"
    pasos={[
      "$8^2 + b^2 = 10^2$",
      "$64 + b^2 = 100$",
      "$b^2 = 100 - 64$",
      "$b = \\sqrt{36} = 6$"
    ]}
  >
    <Ordenacion.ErrorComun titulo="Taking the square root before computing the difference">
      The <ConceptLink targetId="raiz-cuadrada">square root</ConceptLink> does not distribute over subtraction: $\sqrt{100 - 64} \neq \sqrt{100} - \sqrt{64} = 10 - 8 = 2$. First compute the difference $100 - 64 = 36$, then take the root.
    </Ordenacion.ErrorComun>

    <Ordenacion.Resolucion>
      The correct order is:
      - Setting up: $8^2 + b^2 = 10^2$
      - Computing the powers: $64 + b^2 = 100$
      - Solving for $b^2$: $b^2 = 100 - 64 = 36$
      - Taking the square root: $b = \sqrt{36} = 6$
    </Ordenacion.Resolucion>
  </Ordenacion>
</ExerciseStep>
