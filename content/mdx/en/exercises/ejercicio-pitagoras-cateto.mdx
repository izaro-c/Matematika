  <Pregunta

    opciones={[

      { value: 'opt_hipotenusa_err', texto: "$10^2 + a^2 = 8^2$", feedback: "You added the squared hypotenuse to the unknown leg. The squared hypotenuse must stand alone on one side of the equality: $a^2 + b^2 = c^2$." }

  >
    <Pregunta.ErrorComun titulo="Adding the squares instead of subtracting">
      A common error when solving for a leg is adding the known squared lengths: $a^2 = c^2 + b^2 = 100 + 64 = 164 \implies a \approx 12.8$. In any right triangle, the hypotenuse is strictly the longest side ($c > a$ and $c > b$); a leg can never exceed the hypotenuse.
    </Pregunta.ErrorComun>

    <Pregunta.Resolucion>
      By the Pythagorean theorem $a^2 + b^2 = c^2$. Substituting the known quantities $b = 8$ and $c = 10$, we obtain:
      
      <Formula>
        $$ a^2 + 8^2 = 10^2 $$
      </Formula>
    </Pregunta.Resolucion>

    <Emparejar.Resolucion>

      <Formula>

    <Ordenacion.ErrorComun titulo="Extracting square root before completing the subtraction">
      The square root cannot be evaluated term by term ($\sqrt{100 - 64} \neq \sqrt{100} - \sqrt{64} = 10 - 8 = 2$). First compute the difference $100 - 64 = 36$, then extract the root.
    </Ordenacion.ErrorComun>

    <Ordenacion.Resolucion>
      The correct deductive order is:
      - Equation setup: $a^2 + 8^2 = 10^2$
      - Computing powers: $a^2 + 64 = 100$
      - Isolating the unknown square: $a^2 = 100 - 64 = 36$
      - Taking the square root: $a = \sqrt{36} = 6$
    </Ordenacion.Resolucion>
  </Ordenacion>
</ExerciseStep>
