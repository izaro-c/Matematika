<Capitular letra="C" />lassifying geometric figures according to angular properties is an essential skill for applying theorems of <ConceptLink targetId="congruencia">congruence</ConceptLink> and <ConceptLink targetId="semejanza">similarity</ConceptLink>. In this exercise, you will classify different <ConceptLink targetId="triangulo">triangle</ConceptLink> configurations based on their interior angles, construct the classification count matrix, and inspect them on the interactive canvas.

<ExerciseStep
  id="p1"
  numero={1}
  titulo="Classification by Interior Angles"
  questionIds={["p1_q1"]}
>
  Drag each triangle into the appropriate category based on the measure of its angles:

  <Clasificador
    id="p1_q1"
    pregunta="Classify the following triangles into their corresponding categories:"
    buckets={[
      { id: "rectangulo", title: "Right triangle (one angle of 90°)" },
      { id: "acutangulo", title: "Acute triangle (all 3 angles < 90°)" },
      { id: "obtusangulo", title: "Obtuse triangle (one angle > 90°)" }
    ]}
    items={[
      { id: "t1", content: "$90^\\circ, 45^\\circ, 45^\\circ$", bucketId: "rectangulo" },
      { id: "t2", content: "$60^\\circ, 60^\\circ, 60^\\circ$", bucketId: "acutangulo" },
      { id: "t3", content: "$120^\\circ, 30^\\circ, 30^\\circ$", bucketId: "obtusangulo" },
      { id: "t4", content: "$3, 4, 5\\text{ (sides)}$", bucketId: "rectangulo" }
    ]}
  >
    <Clasificador.ErrorComun titulo="Confusing the Pythagorean triple or obtuse angles">
      Remember that by the <ConceptLink targetId="teorema-pitagoras">Pythagorean theorem</ConceptLink> ($3^2 + 4^2 = 5^2$), sides 3, 4, and 5 form a right triangle. Furthermore, a single angle exceeding 90° is sufficient for a triangle to be obtuse.
    </Clasificador.ErrorComun>

    <Clasificador.Resolucion>
      - **Right Triangles**: Have one 90° angle ($90^\circ, 45^\circ, 45^\circ$ or side triple $3, 4, 5$).
      - **Acute Triangles**: All 3 interior angles are strictly less than 90° ($60^\circ, 60^\circ, 60^\circ$).
      - **Obtuse Triangles**: Contain one interior angle strictly greater than 90° ($120^\circ, 30^\circ, 30^\circ$).
    </Clasificador.Resolucion>
  </Clasificador>
</ExerciseStep>
